# RE-Actor

The purpose of this project is to perform pattern matching on the log output of an application. Once a pattern matches, then an action should be taken. Currently, the plan is to read the logs from a running container in Docker. The pattern will most likely be regular expression based.

Here is a list of milestones indicating the progress of the project:
 1. ❌ Read logs from a running Docker container.  
 2. ❌ Perform pattern matching against the logs.
 3. ❌ Perform an action, eg a web request.
